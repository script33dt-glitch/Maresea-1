# MARESEA — vitrine virtual

Site estático (HTML, CSS e JavaScript) com duas páginas: `index.html` e `colecao.html`.

## Como atualizar
Tudo é editado em `script.js`:
1. **WhatsApp:** troque `WHATSAPP_NUMBER` pelo número da loja (só dígitos, com DDI e DDD, ex.: `5511999999999`).
2. **Produtos:** edite a lista `PRODUTOS` (nome, preço, categoria, fotos). `f:1` faz o produto aparecer em destaque na página inicial.
3. **Fotos:** coloque na pasta `images/` com os nomes `nome-1.jpg` (principal) e `nome-2.jpg` (aparece ao passar o mouse). Use fotos verticais de cerca de 640×960 px.

Os nomes e preços atuais são provisórios.

## Publicar no GitHub Pages
Envie a pasta para um repositório, depois em *Settings → Pages* escolha a branch `main` e a pasta `/ (root)`.
